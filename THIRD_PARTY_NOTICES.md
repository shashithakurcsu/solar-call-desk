# Third-party components and services

`Package.swift` declares no external Swift package dependencies. This repository does not vendor audio drivers, SDK binaries, service credentials, or third-party calling applications.

- **Apple frameworks and developer tools:** AppKit, SwiftUI, AVFoundation, AudioToolbox, Core Audio, CoreGraphics, CoreText, Vision, ScreenCaptureKit, Security, and other system APIs are supplied by the Apple SDK and OS. Their respective Apple terms apply. The source references known Apple process paths to verify UI ownership; it does not bundle those applications or link private telephony frameworks.
- **BlackHole:** optional, separately installed virtual audio devices. [Upstream source and license](https://github.com/ExistentialAudio/BlackHole/blob/master/LICENSE) identify GPL-3.0 for source and separate restrictions for official binaries/installers and branding. No BlackHole source, binary, installer, logo, or artwork is distributed in this repository. Obtain drivers from the [upstream project](https://github.com/ExistentialAudio/BlackHole).
- **OpenAI:** the app connects to the Realtime API using a user-provided key. No OpenAI SDK or model weights are bundled. Service access, billing, and data handling remain governed by the user's account and [OpenAI terms](https://openai.com/policies/).
- **Phone and WhatsApp:** separately installed calling applications, not included in this repository. Their names describe supported or experimental integration targets, not affiliation or endorsement.
- **App icon:** generated by the included `scripts/generate-icon.swift` and `scripts/pack-icon.py`. The drawing source is covered by this project's MIT license.

MIT licensing applies to this project's code and documentation; it does not relicense these external components or services. The MIT text follows the [SPDX MIT template](https://spdx.org/licenses/MIT.html).
